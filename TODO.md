# План pob2_engine

Согласован 20 ноября 2026 года. Реализованы сервис сессий Go/CLI/gRPC/MCP, обнаружение сервера, аренды клиентов, автоматическое завершение и восстановление с диска. В `0.0.2` доступны расчёты Fireball/Frostbolt/Spark, каталог и предпросмотр поддержек через CLI/MCP/gRPC с сохранением полной сборки и результатов. Архитектура и исходные ревизии описаны в [README.md](README.md), изменения фиксируются в [CHANGELOG.md](CHANGELOG.md).

Выпуски [0.0.1](todo_0.0.1.md), [0.0.2](todo_0.0.2.md) и
[0.0.3](todo_0.0.3.md) завершены. Для 0.0.3 приняты расчёт через PoB под
LuaJIT, установка и обновление движка и PoB; опубликованные бинарники
проверены на Windows x64, Linux x64 и macOS arm64.

Следующий выпуск — [0.0.4](todo_0.0.4.md): полный каталог оригинального PoB,
правки камней и пассивов по его данным, уровни и качество предпросмотра,
диагностика совместимости и восстановление прежних ответов без нового каталога.

Отмечать задачу выполненной нужно по её проверяемому результату. Подготовка контракта, работающая заглушка, сравнение расчётов PoB и испытание в игре — разные результаты.

**Порядок работы:** сначала самостоятельный расчётный движок. Контракты,
сервер, команды и подписки gRPC разрабатываем сейчас и проверяем отдельными
клиентами. Подключение настоящего Flutter-приложения и его приёмку выполняем
после готовности движка; работа над Flutter пока отложена.

## 0. Согласованные решения

- [x] Название проекта и репозитория: `pob2_engine`.
- [x] Язык движка, CLI и встроенного MCP: Go.
- [x] Связь с существующим Flutter-приложением: gRPC / Protobuf.
- [x] Один сервис владеет состоянием; UI, CLI и MCP используют общие команды и явно выбранные сессии.
- [x] Движок работает без Flutter и графического окна.
- [x] Flutter подключается к существующему серверу или запускает его при отсутствии.
- [x] Автоматически запущенный сервер завершается после отключения всех клиентов и окончания задач; вручную запущенный постоянный сервер остаётся работать.
- [x] Аренды клиентов, защита одновременного запуска и graceful shutdown входят в обязательные требования.
- [x] Источник правил — оригинальные Lua-файлы PoB. По умолчанию их выполняет LuaJIT. Сервис сессий и проверка команд работают на Go.
- [x] Публичный репозиторий, README, TODO, CHANGELOG и выпуск через GitHub Actions по тегу `v*` входят в начальную подготовку.
