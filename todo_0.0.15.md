# Единый движок и очистка поставки 0.0.15

Работы выпущены в pob2_engine v0.0.16 и PoB II v1.0.3.
[Итоговая приёмка](testdata/releases/0.0.16/README.md).

## Движок

- [x] Передать рабочие копии XML через сгенерированный gRPC API. MCP и gRPC используют одну реализацию операций и отрисовки.
- [x] Удалить выбор прежнего расчёта из обычных команд. CLI, MCP и gRPC используют исходный Lua PoB через LuaJIT.
- [x] Подготовить сборку и встраивание LuaJIT и lua-utf8 для Linux x64 и macOS arm64 из закреплённых исходников.
- [x] Проверить штатный расчёт, сохранение сессий и восстановление ответов команд на Windows.

## PoB II

- [x] Включить сгенерированный Dart API в исходники клиента.
- [x] Перевести рабочие копии на gRPC. Для MCP окна и импорта из оригинального PoB использовать команды комплектного движка.
- [x] Убрать установку Python-компонентов из штатной сборки.
- [x] Проверить Windows с реальными расчётами Lua, рабочей копией gRPC, редакторами, внешним MCP, XML и PNG.
- [x] Отделить служебные связи графа от видимых линий дерева и показать подключение к PoB2Engine в интерфейсе.
- [x] Добавить страницу PoB2Engine для управления версиями и диагностики.
- [x] Выполнить сквозную приёмку и проверить установщики Windows x64, Linux x64 и macOS arm64 с новой версией движка.

наличие публичных контрактов и закрытие рабочих процессов.
