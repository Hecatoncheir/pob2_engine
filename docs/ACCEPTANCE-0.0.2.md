## Что проверяет каждый архив

Архивы собираются на Linux с CGO_ENABLED=0 и версией тега. Каждый запускается
на своей ОС: Windows amd64, Linux amd64, macOS arm64. После успешных первых
проверок кандидат публикуется как prerelease. Затем на каждой ОС скачиваются
архив и SHA256SUMS, сверяется сумма и повторяется тот же сценарий.

| Проверка | Ожидаемый результат |
| --- | --- |
| Состав и версия | SHA-256 всех файлов, COMMIT и тег совпадают; реальная платформа соответствует архиву |
| Одноразовый CLI | Fireball/Frostbolt/Spark: complete, новый набор, DPS 8.9166666666667 / 9.1 / 8.5642857142857 |
| Общая сессия | Для каждого умения импорт CLI, +100% Spell Damage через MCP, сохраняемый расчёт CLI через gRPC; ревизия 4, удвоенный DPS |
| MCP и каталог | tools/list содержит ровно девять инструментов; каталог находит каждое умение |
| Поддержки | По два предпросмотра в каждой сессии: Rapid Casting I меняет скорость, Controlled Destruction отключает критические попадания; исходный снимок прежний |
| Сравнение и экспорт | Вариант +200% Spell Damage рассчитан без правки сессии, экспорт совпадает с сохраняемым XML |
| Backup/Verify/Restore | Три сессии и первоначальные ответы восстановлены; схема 2, ровно 12 подтверждённых команд |
| Обновление с 0.0.1 | Из реальной базы возвращается прежний снимок/ответ; новый расчёт меняет ID/хеш набора, сохраняет входы и показатели; старый повтор не откатывает состояние |
| Перезапуск обновлённой сессии | Восстанавливаются оба ответа и текущий снимок; схема 2, ровно четыре записи; исходный эталон базы неизменён |

Допуски чисел: rel=1e-10, abs=1e-9. Исторический ответ и XML проверяются
точным сравнением. [Эталон обновления](../testdata/compat/0.0.1/README.md)
создан скачанным выпущенным `0.0.1`, а не текущим тестовым кодом.

Python исполняет проверяющий сценарий; дочерний движок работает с пустым PATH,
изолированными HOME/APPDATA/XDG и отсутствующим каталогом PoB. Flutter не участвует.
Это проверка поведения расчётов PoB и сессий, а не испытание сборок в игре.
