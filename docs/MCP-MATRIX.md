# Соответствие инструментов MCP для 0.0.2

Матрица относится к разработке `pob2_engine 0.0.2` и закреплённому
`pob-poe2-mcp v0.24.1`, commit `312b337fa4a24f5ef55ebd38c8fd7bd46c7de78a`.
Это сопоставление возможностей: имена инструментов, аргументы и форматы ответов
различаются. Клиенту нужен явный переход на контракт движка.

Источник 46 имён — [tools.json закреплённого MCP](https://github.com/Hecatoncheir/pob-poe2-mcp/blob/312b337fa4a24f5ef55ebd38c8fd7bd46c7de78a/pob_poe2_mcp/data/tools.json).
SHA-256 файла: `da567fcdd8240596f2439a6891bfc2dfecd9eba57c5ae2afae3ae367be6c1cac`.
Доступность прежних инструментов зависит от режима `engine`, `app`, `editor`;
она определяется [server.py](https://github.com/Hecatoncheir/pob-poe2-mcp/blob/312b337fa4a24f5ef55ebd38c8fd7bd46c7de78a/pob_poe2_mcp/server.py)
и [editor.py](https://github.com/Hecatoncheir/pob-poe2-mcp/blob/312b337fa4a24f5ef55ebd38c8fd7bd46c7de78a/pob_poe2_mcp/editor.py).
Таблица охватывает весь манифест, а не один режим.

## Инструменты движка

CLI создаёт сессию; `mcp --attach ID --profile ИМЯ` выбирает её для всех вызовов.
`--standalone --session ID` создаёт отдельную сессию в памяти, которая исчезает
при завершении процесса. Для сохранения используйте подключение к профилю.

| Инструмент 0.0.2 | Действие | Изменяет сессию |
| --- | --- | --- |
| `get_snapshot` | Имя, ревизия, XML, модель, последний сохранённый расчёт | Нет |
| `rename_build` | Переименование, сохранение входа и расчёта | Да |
| `import_build` | Импорт XML с сохранением неизвестного содержимого; расчёт отдельной командой | Да |
| `edit_build` | Одна правка: level, config, gems, equipment, passives, selection | Да |
| `calculate_build` | Расчёт выбранного снимка и сохранение результата | Да |
| `compare_build` | Сравнение с XML или одной правкой | Нет |
| `export_build` | Сохранённый XML и хеш | Нет |
| `get_catalog` | Поиск gems/classes/items/passives с ограничением страницы | Нет |
| `preview_support` | Одна поддержка 1/0 в полной копии выбранной группы | Нет |

Правки и сохраняемый расчёт требуют `expected_revision` и `request_id`.
Сравнение и предпросмотр требуют текущую ревизию; каталог, чтение и экспорт — нет.
Точный повтор принятой команды возвращает первоначальный ответ, даже если
текущая сессия уже изменилась. Успех публикуется после commit.

`calculate_build` сохраняет также результат со статусом `partial` или
`unsupported`. Это обычный ответ инструмента: проверяйте `status` и `issues`.
При `unsupported` чисел нет (`stats: null`); пустые дельты не означают нулевую
разницу. Ошибки операций возвращаются как ошибки инструмента, а ошибки
протокола/схемы могут быть ошибками JSON-RPC. Расчёты выполняет Go в
[объявленном покрытии](COVERAGE-0.0.2.md).

## Переход с прежнего MCP

«Ограниченный аналог» означает только указанную часть операции и расчётного
покрытия. «Другой порядок» требует нескольких команд. «Нет» означает отсутствие
соответствующего инструмента в движке; сохранённый XML сам по себе его не заменяет.
Запись `edit_build.gems` ниже означает поле `edit.gems` вызова `edit_build`.
Расчётные границы не запрещают хранить неизвестный XML: поддержка проверяется
отдельным расчётом, который может вернуть `unsupported`.

| Прежний инструмент | Статус в 0.0.2 | Соответствие и границы |
| --- | --- | --- |
| `pob_get_build_directory` | Нет | Профиль хранит журнал движка; папка сборок установленного PoB не запрашивается |
| `pob_list_characters` | Нет | Доступ к авторизованному окну и списку персонажей не перенесён |
| `pob_get_character` | Нет | Получение персонажа из аккаунта не перенесено |
| `pob_import_character` | Нет | Можно импортировать готовый XML через import_build; объект персонажа не принимается |
| `pob_catalog` | Ограниченный аналог | get_catalog: только камни, базовые классы, пять баз предметов и известные пассивы; нет полного каталога config/слотов/дерева |
| `pob_create_build` | Другой порядок | CLI session create создаёт пустую сессию, затем нужен import_build с готовым XML; генератора новой сборки нет |
| `pob_import_xml` | Ограниченный аналог | import_build сохраняет XML; затем calculate_build. Сам импорт не подтверждает расчётную поддержку |
| `pob_add_skill_group` | Ограниченный аналог | edit_build.gems с group_id=0 добавляет группу; рассчитывается одна включённая группа с одним активным умением |
| `pob_add_item` | Ограниченный аналог | edit_build.equipment задаёт raw в существующем слоте; только объявленные украшения, без добавления в инвентарь без слота |
| `pob_set_config` | Ограниченный аналог | edit_build.config меняет одно условие за вызов; неизвестное условие даёт unsupported при расчёте |
| `pob_set_custom_mods` | Ограниченный аналог | edit_build.config: name=customMods, value.type=string; замена текста, ограниченная грамматика свойств |
| `pob_tree_action` | Ограниченный аналог | edit_build.passives заменяет полный список узлов; старт класса и цепочка Sorceress, без автоматического поиска пути, мастерств и заметок узлов |
| `pob_tree_options` | Ограниченный аналог | edit_build.selection выбирает существующие наборы и оружейный режим; класс задаётся XML, возвышения не рассчитываются |
| `pob_select_main_skill` | Ограниченный аналог | edit_build.selection.main_group и выбор набора; первое активное умение, statSetIndex=1, режим задаётся поддержанным камнем |
| `pob_node_tooltip` | Нет | Оригинальные подсказки, пути и расчётные изменения узла не перенесены |
| `pob_check_build` | Ограниченный аналог | calculate_build и get_snapshot: выбранные показатели, modifiers/issues; без полного отчёта Lua, targets и проверки легальности в игре |
| `pob_export_xml` | Ограниченный аналог | export_build возвращает сохраняемый XML; это не SaveDB Lua, код обмена и запись файла не выполняются MCP-инструментом |
| `pob_render_image` | Нет | PNG и отрисовка отчётов не перенесены |
| `pob_get_tree` | Нет | Геометрия, сцена и полный граф дерева не перенесены |
| `pob_tree_icons` | Нет | Изображения узлов не поставляются |
| `pob_tree_textures` | Нет | Текстуры и токены сцен не перенесены |
| `pob_tree_hover` | Нет | Подсказки наведения и подсветка маршрутов не перенесены |
| `pob_node_power` | Нет | PowerBuilder, тепловая карта и задания оценки узлов не перенесены |
| `pob_gem_icons` | Нет | Изображения камней не поставляются |
| `pob_gem_supports` | Ограниченный аналог | get_catalog и preview_support для Rapid Casting I/Controlled Destruction; нет подбора для произвольного черновика, targetIndex и оценки вместимости |
| `pob_preview_support` | Ограниченный аналог | preview_support использует полную выбранную группу сохранённой сессии; только две поддержки уровня 1, качества 0 |
| `pob_compare_supports` | Ограниченный аналог | Отдельные preview_support с одной исходной ревизией; атомарного пакетного сравнения 1–8 кандидатов нет |
| `pob_update_skill_group` | Ограниченный аналог | edit_build.gems заменяет весь состав группы по group_id в текущем наборе; сохраняемые камни нужно перечислить явно |
| `pob_delete_skill_group` | Ограниченный аналог | edit_build.gems с group_id и delete=true; выбор главной группы нормализуется |
| `pob_inspect_item` | Нет | Отдельный подробный разбор предмета и подсказки не перенесены; raw и диагностика доступны в снимке/расчёте |
| `pob_equip_item` | Ограниченный аналог | edit_build.equipment заменяет предмет по slot/raw, пустой raw снимает; выбора существующего itemId отдельной командой нет |
| `pob_select_weapon_set` | Ограниченный аналог | edit_build.selection.weapon_set выбирает 1/2; активное оружие всё ещё вне расчётного покрытия |
| `pob_gem_tooltip` | Нет | Оригинальные подсказки и все свойства камней не перенесены |
| `pob_compare_item` | Ограниченный аналог | compare_build с правкой equipment: только поддержанные базы, слоты и свойства |
| `pob_trade_catalog` | Нет | Каталог торговли не перенесён |
| `pob_trade_search` | Нет | Построение торгового поиска не перенесено |
| `pob_editor_status` | Нет | Подключение к работающему Flutter-редактору отложено |
| `pob_editor_app` | Нет | Управление приложением отложено |
| `pob_editor_components` | Нет | Управление компонентами приложения отложено |
| `pob_editor_library` | Нет | Библиотека XML приложения не перенесена; сессии профиля имеют другой контракт |
| `pob_editor_history` | Нет | Undo/redo редактора не перенесены; журнал и повторы команд движка не являются undo/redo |
| `pob_editor_notes` | Нет | Редактирование заметок через MCP не перенесено |
| `pob_editor_files` | Нет | Диалоги и действия файлового интерфейса не перенесены |
| `pob_editor_progression` | Нет | Управление этапами прокачки не перенесено |
| `pob_editor_ui` | Нет | Разделы, диалоги, снимки и действия интерфейса отложены |
| `pob_editor_job` | Нет | Задания редактора не перенесены; прогресс calculate_build имеет отдельный контракт |
