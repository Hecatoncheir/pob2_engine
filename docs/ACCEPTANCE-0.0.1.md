# Приёмка 0.0.1

## Подтверждённое покрытие

Go рассчитывает [объявленный набор Fireball Projectile](COVERAGE-0.0.1.md).
Матрица Lua содержит 77 вариантов: 75 полных, один с предупреждением
требований камня и один неподдержанный модификатор. Сравниваются 27 показателей,
промежуточные значения и диагностика. Допуски: относительный `1e-10`, абсолютный
`1e-9`. Другие умения и механики не объявляются поддержанными.

[Linux CI](https://github.com/Hecatoncheir/pob2_engine/actions/runs/44834168503)
прошёл анализ, тесты, `-race`, лицензии, данные, протокол и генерацию API.
Отдельные процессы проверяют одинаковое состояние CLI/MCP/gRPC, все шесть
типов правок, события, конфликты, повторы, резервные копии, обычный перезапуск
и Kill. Проверки отказа записи, повреждений, неизвестных версий, отмены,
зависшей задачи и медленного читателя входят в тесты. Это не испытание
физического отказа диска. [Замеры и среда](../testdata/performance/README.md).

## Кандидат

[v0.0.1-rc.1](https://github.com/Hecatoncheir/pob2_engine/releases/tag/v0.0.1-rc.1),
commit `52d52b44ed3f3f7e258d763210f136a468a991ba`.
[Полный релизный workflow](https://github.com/Hecatoncheir/pob2_engine/actions/runs/44834517225)
прошёл кросссборки, запуск архивов и повторный запуск скачанных файлов.

| Платформа запуска | Архитектура | Отчёт скачанного файла |
| --- | --- | --- |
| Windows Server 2025 | amd64 | [JSON](../testdata/releases/0.0.1-rc.1/published_smoke_windows_amd64.json) |
| Linux, ядро 7.0.0-1020-azure | amd64 | [JSON](../testdata/releases/0.0.1-rc.1/published_smoke_linux_amd64.json) |
| macOS 15.8.2 | arm64 | [JSON](../testdata/releases/0.0.1-rc.1/published_smoke_darwin_arm64.json) |

Каждый архив проверен по SHA-256. С пустым PATH и без исходников PoB выполнены
расчёт, общая сессия CLI/MCP через gRPC, сравнение без изменения состояния,
экспорт, Backup/Verify/Restore и точный повтор сохранённого расчёта.
Исходный пример: `TotalDPS = 8.9166666666667`; после увеличения урона
заклинаний на 100%: `17.8333333333333` в пределах допуска. Дополнительно
скачанный Windows-архив прошёл тот же сценарий на Windows 11.
[Суммы](../testdata/releases/0.0.1-rc.1/SHA256SUMS) и
[commit](../testdata/releases/0.0.1-rc.1/COMMIT.txt) сохранены.

Кандидат подтверждает готовность реализации; итоговый тег `v0.0.1` проходит
эти же проверки заново. Итог публикации фиксируется отдельно после скачивания
финальных файлов. Flutter не изменялся и в приёмке не участвовал. Расчёты
проверены по PoB, а не в игре; ускорение относительно Lua не заявляется.
