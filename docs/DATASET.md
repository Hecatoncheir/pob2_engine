# Набор данных Go

Набор `pob2-0.0.1-fireball-v1` встроен через `go:embed` в
`internal/gamedata/files/`. Установке не нужны Lua, Python, сеть или каталоги PoB.
Загрузчик проверяет схему, дерево, SHA-256 каталога, происхождение, уникальность
идентификаторов, диапазоны чисел, уровни камней и двусторонние связи пассивов.
Повреждённый набор возвращает ошибку до использования.

## Состав и границы

- `manifest.json`: схема 1, идентификатор набора, ревизия PoB, дерево `0_5`,
  SHA-256 источников и экспортёра, условия и характер преобразования.
- `catalog.json`: 8 классов, Fireball уровней 1–20, Rapid Casting I,
  Controlled Destruction, 5 баз украшений, стартовые узлы классов и начальная
  цепочка Sorceress, необходимые числовые константы.

`game_version: null` означает, что версия игры не установлена. Данные класса
в каталоге не означают поддержку всех его механик; покрытие расчёта объявляется
отдельно. Набор не содержит изображений, описаний умений и полного дерева.

Из Lua извлекаются факты и числовые параметры. Грамматика поддерживаемых
модификаторов, порядок вычислений и решения о покрытии реализуются отдельно
в Go. Расчётные результаты из эталона не используются как готовый ответ движка.

## Воспроизведение

После подготовки [эталонной среды](../testdata/reference/README.md):

```shell
python -X utf8 tool/export_data.py --write
python -X utf8 tool/export_data.py
go test ./internal/gamedata
```

`--write` явно обновляет набор. Обычный запуск сравнивает байты и не изменяет
его. Экспорт использует `tool/export_data.lua`, закреплённый runner MCP,
проверенные источники PoB и отдельные HOME/APPDATA/XDG. Классы, камни, базы
и узлы сортируются; односторонние записи рёбер исходного JSON преобразуются
в симметричный граф. Числовые требования камней вычисляет исходный `CalcTools`.
CI повторяет экспорт на Linux и проверяет точное совпадение файлов.

Сохранены уведомления `Skill, gem and item data (c) Grinding Gear Games`;
лицензия нового Go-кода не назначается игровым данным. Исходная объединённая
лицензия PoB включена в комплект уведомлений. Политика и перечень материалов —
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

При изменении источников сначала обновите pin и происхождение, затем экспорт,
проверьте разницу и повторите эталоны. Замена набора из сети и автоматическая
активация внешних данных в `0.0.1` не предусмотрены.
