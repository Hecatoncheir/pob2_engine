# Каталог и предпросмотр поддержек

Добавлены в разработке `0.0.2`. Общий контракт `application.CatalogCommands`
используется CLI, MCP и gRPC. Flutter пока не подключается.

В 0.0.3 LuaJIT рассчитывает импортированный XML и варианты предпросмотра.
Поиск и операции, которые добавляют камни, выбирают базу предмета или
назначают пассивы, используют встроенный каталог Go. Импорт сохраняет XML
с данными за пределами каталога.

## Поиск данных

`Catalog` / `GetCatalog` / MCP `get_catalog` возвращают страницу текущего
встроенного набора: `data_id`, SHA-256, закреплённый `pob_commit`, версию дерева
и записи. Каталог доступен без сборки; подключение к серверу требует обычной
авторизации. MCP работает внутри явно выбранной сессии.

| `kind` | Содержимое |
| --- | --- |
| `gems` | Fireball, Frostbolt, Spark; Rapid Casting I, Controlled Destruction |
| `classes` | Восемь базовых классов, без возвышений |
| `items` | Пять баз украшений и разрешённые слоты |
| `passives` | Стартовые узлы и проверенная цепочка Sorceress, с `class_ids` |

У записи есть точный `id`, имя, `aliases` и ограничения `coverage`. Для камней
также возвращаются уровни, качества, режимы и семейство поддержки. Пустой массив
означает неприменимое поле. Наличие базы предмета или класса **не означает**
поддержку всех его свойств, дерева или механик.

`query` ищет подстроку ID, имени или псевдонима без учёта регистра; крайние
пробелы удаляются. Точный идентификатор выбирайте из результата. Максимум —
256 байт UTF-8; `limit` — 1–100, значение 0 задаёт 20; `offset` — 0–10000.
Результаты упорядочены по ID, `total` — число совпадений до разбивки на страницы.
За концом каталога возвращается `entries: []`. Некорректные параметры получают
`invalid_argument`, без молчаливого уменьшения лимита.

```shell
pob2-engine catalog --profile main --kind gems --query RapidCastingSupport
pob2-engine catalog --profile main --kind passives --query 18845 --limit 10
```

## Предпросмотр полной группы

`PreviewSupport` / MCP `preview_support` принимают `session_id` (в MCP выбран
при подключении), `expected_revision` и точный ID либо псевдоним поддержки.
Уровень добавляемой поддержки — 1, качество — 0; другие варианты пока отсутствуют.

```shell
pob2-engine preview-support --profile main --session build-1 --revision 2 --support "Rapid Casting I"
```

Сервис фиксирует текущий снимок и добавляет поддержку в копию выбранной группы
текущего набора умений. Остальные камни, их параметры, группы, наборы и неизвестный
XML сохраняются. Расчётчик сравнивает полные документы, проверяя совместимость,
повтор **включённого** семейства и остальные ограничения сборки. Отключённая
поддержка не занимает семейство. Предпросмотр ничего не устанавливает в сессию.

Ответ содержит исходную ревизию, `group_id`, описание поддержки, `compatible`,
`status`, `comparison.before/after/deltas`. Оба результата содержат собственные
хеши входов и набора данных. `compatible: true` означает, что оба варианта имеют
числа в объявленном покрытии; предупреждения дают `partial`. При `unsupported`
читайте `issues` обоих вариантов: причина может относиться к самой сборке.
Неподдержанный результат имеет `stats: null` и пустые дельты, без нулевой подмены.
Неизвестная поддержка/активный камень и отсутствующая группа дают ошибку ввода;
старая ревизия — конфликт. Пустая сессия сначала требует импорта XML.

Используется та же очередь, что для расчёта и сравнения: четыре выполняемые,
20 допущенных задач. Переполнение — `resource_exhausted`, отмена освобождает
ожидание. Параллельная правка не меняет уже зафиксированные входы: ответ остаётся
привязан к исходной ревизии. Перед применением варианта перечитайте снимок.
Новой ревизии, события, сохранённого расчёта или записи журнала не появляется.
`request_id` не требуется. CLI возвращает 0/3/4 для complete/unsupported/partial,
сохраняя JSON результата; обычная ошибка выполнения — 1, синтаксиса — 2.
LuaJIT передаёт предупреждения PoB в `issues` с кодом `pob_warning`.
Нераспознанные строки активных пользовательских модификаторов получают
`unsupported_modifier`. В обоих случаях рассчитанные показатели доступны
со статусом `partial`.

## Проверки

[Процессная проверка](../internal/integration/catalog_process_test.go) сравнивает
три адаптера, поиск, страницы, группы всех трёх умений, сочетание поддержек,
повтор семейства и отсутствие лишних событий. [Сервисные тесты](../internal/application/support_test.go)
проверяют журнал, очередь, отмену, параллельную правку и диагностику.
[Числовая проверка](../internal/calculation/support_test.go) использует девять
существующих эталонов Lua; новые формулы и изменение закреплённого набора не нужны.
