# План выпуска pob2_engine 0.0.10

В общей сборке PoB II можно выбрать пассив, увидеть затронутые узлы и
изменение показателей, затем подтвердить правку активного дерева.

## Движок

- [x] Передавать ID узла и действие (`allocate` или `refund`) в
  `CompareBuild` и `ApplyBuild`. Оригинальный PoB строит путь назначения
  и определяет зависимые узлы при снятии. Для новых узлов атрибутов
  использовать выбор PoB по умолчанию. Специализации, мастерства, гнёзда
  и ветви комплектов оружия требуют отдельного сценария.
- [x] Сохранять прочие спецификации и расширения XML. Предпросмотр
  возвращает список добавляемых и снимаемых узлов, показатели и
  диагностику без записи. Применение защищено ревизией и `request_id`.
- [x] Проверить назначение, снятие, отказ, конфликт ревизий, сохранность
  XML и совпадение предпросмотра с применением. Запустить проверки
  CLI, MCP и отдельного gRPC-клиента с оригинальным Lua PoB до работы над
  интерфейсом. [Эталон](testdata/reference/0.0.10/README.md).

## PoB II

- [x] В общей сборке показать активную спецификацию и дать выбрать узел
  по имени из каталога PoB или по ID. Показать затронутые узлы, показатели
  и предупреждения.
- [x] Применять подтверждённый предпросмотр для той же сессии, ревизии
  и подключения. Обновлять общую сборку по `WatchSession`.
- [x] Прогнать локальные проверки и сквозной сценарий на Windows с Lua
  PoB. Проверить правку из интерфейса, доставку новой ревизии и отказ
  применять устаревший предпросмотр после правки через MCP.
