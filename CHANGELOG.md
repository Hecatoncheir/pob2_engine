# История изменений

Изменения фиксируются по версиям. Для автоматического выпуска заголовок версии должен иметь вид `## [0.0.1] - ГГГГ-ММ-ДД` и соответствовать тегу `v0.0.1`. Предварительные версии, например `0.0.1-alpha.1`, оформляются так же. Новые изменения сначала записываются в раздел «Не выпущено».

## [Не выпущено]

### Добавлено

- Платформенные ZIP с проверяемым составом, документацией, примером и полным комплектом уведомлений; запуск готового архива на трёх ОС до публикации.
- Отчёт измерений расчёта и состава среды Linux в CI.

- Типизированный API полной сборки, правок, результатов и сравнения; поток расчёта с учётом активной задачи до фактического завершения.
- CLI `calculate`, `build import|edit|compare|export`, `storage backup|verify|restore`; JSON, коды статусов и экспорт в новый UTF-8 файл.
- Семь MCP-инструментов, прогресс и полный снимок; одинаковый результат CLI/MCP/gRPC в процессной проверке с восстановлением резервной копии.
- Атомарная замена файла обнаружения Windows при открытом читателе; проверка расчёта с пустым PATH без Python/Lua/PoB.

- Общие команды полной сборки: импорт и правки XML, экипировка, камни, пассивы, условия, расчёт с устойчивым сохранением, экспорт и сравнение без изменения сессии.
- Связь результата с ревизией входа и SHA-256 XML/данных, сброс устаревшего результата и восстановление первоначальных чисел без повторного расчёта.
- Ограниченная очередь, совместное ожидание повторного расчёта, неблокирующий прогресс, отмена и защита от сохранения результата старой ревизии.
- Схема журнала 2 с проверенным переходом из схемы 1 после резервной копии; Backup/Verify/Restore в пакете хранения, проверки сохранности полного XML и расчёта, ограничения истории и объёма записи.
- Расчётная библиотека Go для Fireball Projectile: ресурсы, две поддержки, свойства украшений, начальные пассивы, критические попадания, сопротивления, расходы и DPS; происхождение перенесённых формул сохранено.
- Матрица 77 вариантов Lua с контролем ошибок камней и неразобранных свойств, сравнение 27 чисел и промежуточных значений, статусы и отказ выдавать числа для неподдержанного ввода.
- Неизменяющее сравнение двух документов, проверки параллельных расчётов, отмены и игнорирования сохранённого кэша PoB; предварительные замеры времени и выделений памяти.
- Независимая модель сборки и ограниченный импорт XML: выбор активных наборов, камней, предметов и дерева, сохранение неизвестного содержимого и стабильный SHA-256 канонического документа.
- Проверки повторного обмена XML, неверных ссылок и повреждённого ввода; объявлены границы первого расчётного сценария и статусы complete/partial/unsupported.
- Встроенный числовой набор для первого расчёта: классы, Fireball 1–20, две поддержки, пять баз украшений, начальная ветка Sorceress и константы; происхождение и воспроизводимый экспорт из закреплённого Lua.
- Загрузчик Go без Lua/Python: проверка схемы, сумм, ссылок, идентификаторов и диапазонов; проверки повреждённого и несовместимого набора.
- MIT для нового кода, исходные лицензии PoB/MCP и проверяемый комплект уведомлений 15 зависимостей CLI и Go для трёх целевых платформ; ZIP лицензий в будущих выпусках.
- Изолированные исходники эталона, проверка фактического commit и нативных библиотек; минимальный Fireball уровня 1, XML, полный отчёт Lua и SHA-256 входа.
- Повторный расчёт новым процессом, отдельная проверка Lua в Linux CI и сохранение сообщений загрузчика, предупреждений и состава среды.
- План первого полноценного Go-выпуска `todo_0.0.1.md`: объявленное расчётное покрытие, XML, сравнение с Lua, API, сохранение, приёмка и публикация без Flutter.
- Фиксация PoB `v0.23.1` и MCP `v0.24.1`, происхождения пары и семи исходных файлов; проверяющая команда `go run ./tool/reference [-remote]` с SHA-256 и Git blob.
- Отдельный учёт встроенной ревизии PoB в MCP, отличающейся от фактически запускаемого закреплённого эталона.
- gRPC `WatchServer`: текущая фаза и уведомление `draining` до штатного EOF, причина остановки, последовательность одного запуска и верхняя граница ожидания.
- Фазы `starting` → `ready` → `draining` → `stopped`, защита переходов и проверки гонок подписки с остановкой без Flutter.
- Ограничение ожидания закрытия хранилища: таймаут не освобождает профиль преждевременно; ошибки очистки сообщаются клиенту и CLI.
- Проверки зависшего хранилища и медленной подписки, доставка уведомления отдельному gRPC-клиенту и процессное восстановление после shutdown.
- Поток `WatchSession`: начальный снимок, правки по ревизиям, восстановление пропущенных событий после перезапуска; отказ записи и повтор команды не создают событий.
- Приватный режим `connect --connection-json` для gRPC-клиента Flutter с общей арендой и штатным освобождением по EOF.
- Проверки порядка событий, медленного читателя, авторизации, остановки и доставки правок CLI/MCP после восстановления.
- Транзакционный журнал bbolt `v1.5.0`: сохранение сессий, ревизий и исходных результатов команд перед успешным ответом CLI/MCP, восстановление после перезапуска и `Kill`.
- Отдельный каталог данных `--data-dir`, сохраняемый профиль `default`, явный временный режим `--ephemeral`, путь и режим хранения в `info`.
- Проверки версии схемы, контрольных сумм и восстановления; отказ от сброса повреждённых данных и от подключения профиля к серверу без сохранения.
- Модульные и процессные тесты восстановления, повторов, параллельных записей, отказа сохранения и эксклюзивного доступа к базе.
- Обнаружение и явный автозапуск сервера по профилю: атомарный файл подключения, проверка экземпляра и протокола, системные блокировки и восстановление устаревших записей, включая повторное использование порта посторонним сервером.
- Защита каталога профиля и токена правами пользователя, включая DACL Windows; удаление только своего файла подключения после завершения сервера.
- Аренды клиентов UI/MCP/CLI, heartbeat, очистка после аварийного отключения и автоматическая регистрация Go-клиента.
- Автоматический режим жизни: уход последнего клиента, ожидание активных RPC и фоновых задач, задержка переподключения и сохранение постоянного режима.
- Ограниченное ожидание фоновых задач при shutdown, отмена контекста при принудительной остановке и процессные проверки конкурирующего запуска и замены завершающегося экземпляра.
- Рабочий каркас Go 1.27.4: CLI, локальный gRPC-сервер и MCP stdio на официальном Go SDK.
- Общий сервис сессий в памяти: создание, снимок, переименование, ревизии и защита от повторного применения успешных команд.
- Первый Protobuf-контракт и воспроизводимая локальная генерация Go/Dart API с закреплёнными инструментами и Dart lock-файлами.
- Проверка токена и версии протокола, постоянный режим сервера, готовность, ограниченное по времени завершение, attach и standalone MCP.
- Модульные и процессные тесты общего состояния CLI/MCP, конфликтов, повторов, ошибок подключения и завершения; проверки контракта и Dart API в CI.
- Согласованную архитектуру отдельного движка на Go, CLI, встроенного MCP и связи с Flutter через gRPC / Protobuf.
- Требования к общей сессии, управлению приложением, автоматическому запуску сервера, учёту клиентов и graceful shutdown.
- План постепенного переноса расчётов PoB, импорта данных, сравнения с исходным Lua и обновлений с откатом.
- CI только на Linux: документация, анализ, тесты Go и проверка гонок; кросссборки Windows x64, Linux x64 и macOS arm64 без cgo выполняются только при выпуске по тегу.
- Выпуск по тегам `v*`: проверку changelog, архивы исходников, контрольные суммы и сборки CLI после появления Go-программы.

Go рассчитывает объявленный набор Fireball; общий сервис сохраняет полную сборку и расчёт, операции доступны через CLI/MCP/gRPC. gRPC проверяется независимо; наработки Flutter сохранены как черновик в `pob2_ui/1.x.x`, подключение и приёмка приложения отложены до готовности движка. Сессии профиля сохраняются на диск и восстанавливаются после перезапуска. Выпусков с работающим расчётным движком пока нет.
