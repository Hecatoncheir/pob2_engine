# План выпуска pob2_engine 0.0.1

Рабочий план первого полноценного выпуска. [TODO.md](TODO.md) остаётся общей
дорожной картой, а этот файл определяет порядок работ и условия выпуска `v0.0.1`.
Пункты закрываем проверяемым результатом: кодом, фикстурой, отчётом или артефактом.
Само наличие API или успешная компиляция не подтверждает готовность расчётов.

## Цель и границы выпуска

Пользователь получает самостоятельный Go-движок: загружает XML-сборку, меняет её,
рассчитывает показатели, сравнивает варианты, сохраняет результат и продолжает
работу после перезапуска. CLI, MCP и gRPC используют одно ядро и одни сессии.
Исполняемому файлу для расчётов не нужны Python, Lua, Flutter или исходники PoB.
Lua используется при разработке и в CI как закреплённый эталон.

Для `0.0.1` выбран законченный набор поддерживаемых сборок. Начинаем с одного
активного умения, выбранных поддержек и обычных модификаторов предметов и пассивов.
Конкретные идентификаторы и ограничения закрепим после разбора эталонных данных.
Полный паритет с PoB, остальные умения и сложные взаимодействия — последующие выпуски.

- [x] **0.2.** Зафиксировать конкретные поддерживаемые механики, умения,

После каждого шага обновляем этот файл и CHANGELOG, выполняем относящиеся к нему
проверки, коммитим изменения и дожидаемся CI. При изменении объёма сначала
обновляем критерии, затем реализацию. Подключение Flutter остаётся отдельным этапом
после готовности движка.
